# 功能清单与审计

本文按使用路径梳理当前版本的功能、验证方式和已知边界。测试命令：`node --test test/*.test.mjs`。

## 写作与编辑

- Markdown 编辑、实时预览、标题/作者/摘要、导入 `.md` / `.txt` / `.docx` / `.html`
- 大纲导航、编辑器与预览段落联动、段落拖拽/上移/下移/复制/删除
- 图片图注独立编辑、图片替换、1:1 / 4:3 / 16:9 裁剪
- 查找替换、⌘B / ⌘⇧H / ⌘1-3 / ⌘⇧7-8 / ⌘⇧K / ⌘F 快捷键
- 片段库：内置作者简介、关注引导、免责声明；支持变量和自定义片段
- 图片素材库：跨文章复用、上传、插入、删除

## 排版与主题

- 18 套主题、36 个版式变体、主题收藏/最近筛选
- 字号/行高/字距/段距/留白、排版预设、排版体检与一键整理
- 版式 DNA：从参考截图提取纸色、强调色和明暗，生成三个配方
- 封面四布局、公众号文章/信息流/分享卡/搜一搜分发预览
- 实测保真分：13 套主题真实草稿读回结果，新增 5 套待实测，主题卡与发布检查展示

## AI

- 全文/选中段/本节改写，语气预设，token 估算，流式取消
- AI 修改 diff 预览，应用/放弃，段落锁，AI 来源标记
- 编辑部规范：语气、禁用词、偏好词、段落上限、图注要求，进入提示词和发布检查
- AI 风格记忆：记录采用/放弃，把最近采用的改法带入下一次提示

## 发布与运营

- 单/多公众号账号新增、切换、删除；旧单账号自动迁移
- 保存草稿、覆盖更新、多图文逐篇更新、发布检查、发布前质检
- 发布对账单：保存/更新/发布事件、增删行、diff、恢复
- 版本快照、快照 diff、恢复；草稿箱分页、标题搜索、导入/删除
- 发布计划（本地排期，不自动发布）
- 发布复盘：近 7 天阅读/分享数据，无数据权限时降级

## 资产、诊断与体验

- 品牌包：收藏、最近主题、版式 DNA、写作规范、片段导出/导入
- IndexedDB 草稿/快照/账本/片段/风格记忆/图片；localStorage 回退
- 跨窗口 BroadcastChannel 冲突提示
- ErrorBoundary、诊断报告、存储用量、最近错误
- 长文内容跳过、图片懒加载、减少动效、键盘焦点、性能预算测试

## 验证

- 自动化测试：224 个通过
- CI：Node 22 / 24
- 真实账号：单篇/多图文覆盖更新、删除通过；13 套主题保真读回 98–100，新增 5 套待实测
- 保真脚本：36 个变体全量模式；SVG 或 background-image 被丢弃时判失败，可用 WX_FIDELITY_DRY_RUN=1 先做本地结构审计
- 真实发布接口：脚本就绪，默认拒绝执行，只在测试公众号显式开启
- Canvas：封面四布局、DNA 取色、图片裁剪使用真实 canvas 测试

## 已知边界

- 真实 `freepublish` 未对生产账号执行
- AI 文风质量仍属人工判断，自动化验证协议与降级路径
- 发布复盘依赖公众号数据统计权限
- 多账号的品牌资产目前共用一套，账号级品牌隔离尚未实现
